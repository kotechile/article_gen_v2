


Add Image

When user clicks a button to add an image a popup opens where the user can select using AI, load an image from local machine,  loading a stock image or generating an Infographics.
After generating an image and storing it in supabase we will get the image_url. In addition, editable text boxes should be available for metadata for author, AltText, Title, Caption. Metadata fields need to be pre filled  automatically if possible and editable by users (e.g. AI generated image can output metadata based on the prompt).

The output from this process should be stored in a new supabase table ‘Images’ with the following fields (you will need to provide the migration sql to create this table):

user_id
ImageUrl
ImageAuthor
MediaAltText
mediaTitle
mediaCaption


A) Generate AI Image: 


The user can enter an image prompt or If the user selected a paragraph, the system it remembers the paragraph, it will call the default LLM and will generate  a prompt to generate an image.
The user has the option to choose Stable Disuffussion, Google Imagen or Flux Kontext and nanoBanana. The user is also able to select the desired aspect ratio from a dropdown list.
If the model allows it can generate an image based on an uploaded reference image.

For AI model names and keys,   ‘llm_providers_image’ contain the model description and  technical name  with  fields api_keys_id linking to table ‘api_keys’ will provide the API key (linked by api_key_id).

Following are the supported models:



imagen-4.0-generate-001
gemini-2.5-flash-image
gemini-3-pro-image-preview
Stable Image Core (Stable Diffussion)
Flux kontext
Stable Diffusion 3.5 (Stable Diffussion)
imagen-4.0-ultra-generate-001
Imagen 4.0 Fast
imagen-4.0-fast-generate-001



The resulting image should be displayed for evaluation and provide the option to change prompt and/or generate a new image. The prompt can be used as a meta description/ media caption with AI as media author, media alt text.

Please review functionality of each model above and identify functionalities available that can improve the image generation (e.g. Nano Banana can improve an input picture or “Flux Kontext” Object & Text Manipulation or Style Transfer.

To identify the default llm you need to check table llm_providers, field ‘is_default’ = true

With the image generated, the system uploads this image to Supabase storage bucket “User Files” inside folder “articleImages” and inside a user’s own folder named with the user’s  supabase auth id.
The system then retrieves the url of the uploaded image.

B)  Load from local machine

The user can select an image file from their local computer. The system uploads this image to Supabase storage bucket “User Files” inside folder “articleImages” and inside a user’s own folder named with the user’s  supabase auth id.
The system then retrieves the url of the uploaded image.



C) Loading a stock Image:  The user can select sources from Pexels or Unsplash. The user will see a gallery with images and their authors/name are displayed in the screen. The user can select one of them and load to it supabase. The system uploads this image to Supabase storage bucket “User Files” inside folder “articleImages” and inside a user’s own folder named with the user’s  supabase auth id.
The system then retrieves the url of the uploaded image. Api keys can be found in table api_keys. Search for provider unsplash or pexels and you will find the corresponding key_value


D) Generating an Infographic: To generate an infographic, similar the user will select a template from a dropdown list. It will show a sample image so the user can understand the look. Once the user selects the right template, if the user had previously selected a paragraph of text from the article body, the  text will be shown in an editable  text box (if no text was selected the text box will be blank and the user  will have the option to describe what they want to fill the template with or a story that the template should tell).  If there is text in the editable text box then a button is enabled to send the text along with a prompt to the default  LLM that will read the text and create a JSON object with the format required by the template.

async function queryUnsplash() {
  const pageNumber = Inputs.PageNumber || 1;
  const key = Inputs.key;

  // Use optional chaining for safer access to nested properties
  let prompt = Inputs.prompt 

  const url = `https://api.unsplash.com/search/photos?client_id=${key}&query=${(prompt)}&page=${pageNumber}&per_page=10`;
  const method = "GET";

  try {
    const response = await fetch(url, { method });

    if (!response.ok) {
      throw new Error(`Unsplash API error! status: ${response.status}`);
    }

    const data = await response.json();
    const totalPages = data.total_pages;
    Outputs.totalPages=totalPages;
    const firstTenImages = data.results.slice(0, 10).map(image => {
      const authorName = `${image.user?.first_name ?? ""} ${image.user?.last_name ?? ""}`;
      return {
        id: image.id,
        url: image.urls.small,
        urlRaw: image.urls.raw,
        urlThumb: image.urls.thumb,
        urlSmall: image.urls.small,
        urlFull: image.urls.full,
        urlRegular: image.urls.regular,
        userId: image.user?.id, // Optional chaining
        userFirstName: image.user?.first_name, // Optional chaining
        userLastName: image.user?.last_name, // Optional chaining
        downloadUrl: image.links?.download, // Optional chaining
        downloadLocation: image.links?.download_location, // Optional chaining
        author: `Unsplash Image - author: ${authorName.trim()}`,
        description: image.description || "", 
      };
    });
   
    Outputs.firstTenImages = firstTenImages;
    Outputs.data = data;
    Outputs.Success();
    console.log("Success:", firstTenImages); 

  } catch (error) {
    Outputs.error = error.message; // Only send the error message, not the entire object
    Outputs.Failure();
    console.error("queryUnsplash Error:", error);
  }
}

async function queryPexels() {
  const key = Inputs.key;
  const perPage = Inputs.perPage || 10;
  const prompt = Inputs.prompt;
  const pexelsPage = Inputs.pexelsPage || "";
  let url = ""

  // Construct the URL properly
  if (pexelsPage === "Pexels Search") { 
    url = `https://api.pexels.com/v1/search?query=${prompt}&page=2&per_page=${perPage}`;
  } else if (pexelsPage === "Pexels Curated") {
    url = `https://api.pexels.com/v1/curated?per_page=${perPage}`;
  } else {
    url = pexelsPage
  };
  const method = "GET";
  const headers = {
    Authorization: key
  };

  try {
    const response = await fetch(url, { method, headers });

    if (!response.ok) {
      throw new Error(`Pexels API error! status: ${response.status}`);
    }

    const data = await response.json();
    const next_page = data.next_page;
    const prev_page = data.prev_page;
    const totalPages = data.total_results/perPage ;
    const page = data.page;

    Outputs.totalPages = totalPages;
    Outputs.next_page = next_page;
    Outputs.prev_page = prev_page;
    Outputs.curr_page = page;

    // Map the first ten images
    const firstTenImages = data.photos.slice(0, perPage).map(image => ({
      id: image.id,
      width: image.width,
      height: image.height,
      urlPexels: image.url,
      author: "Pexels image by author " + image.photographer,
      photographer_url: image.photographer_url,
      photographer_id: image.photographer_id,
      avg_color: image.avg_color,
      original: image.src.original,
      large2x: image.src.large2x,
      large: image.src.large,
      url: image.src.medium,
      small: image.src.small,
      portrait: image.src.portrait,
      landscape: image.src.landscape,
      tiny: image.src.tiny,
      description: image.alt
    }));

    Outputs.firstTenImages = firstTenImages;
    Outputs.data = data;
    Outputs.Success();
    console.log("Success:", firstTenImages);

  } catch (error) {
    Outputs.error = error.message; // Only send the error message, not the entire object
    Outputs.Failure();
    console.error("queryPexels Error:", error);
  }

async function generateImageWithGoogleImagen(prompt, imagenModel, geminiApiKey) {
    // No more JWT service needed!
    const url = `https://generativelanguage.googleapis.com/v1beta/models/${imagenModel}:generateImages`;
    
    const body = JSON.stringify({
        prompt: prompt,
        config: {
            number_of_images: 1,
            aspect_ratio: "1:1" // or other ratios
        }
    });

    Outputs.status = formatCurrentDate() + ": Request Sent to Google Imagen 3 - Waiting for Image Generation";

    try {
        const response = await fetch(url, {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${geminiApiKey}`, // Simple API key
                'Content-Type': 'application/json'
            },
            body: body
        });

        if (!response.ok) {
            const errorData = await response.json().catch(() => ({}));
            throw new Error(`Google Imagen failed: ${response.status} ${errorData.error?.message || response.statusText}`);
        }

        const responseData = await response.json();
        
        if (responseData.generated_images && responseData.generated_images.length > 0) {
            const imageBytes = responseData.generated_images[0].image.image_bytes;
            
            // Convert base64 to Blob (if needed)
            const byteCharacters = atob(imageBytes);
            const byteNumbers = new Array(byteCharacters.length);
            for (let i = 0; i < byteCharacters.length; i++) {
                byteNumbers[i] = byteCharacters.charCodeAt(i);
            }
            const byteArray = new Uint8Array(byteNumbers);
            const blob = new Blob([byteArray], { type: 'image/png' });
            
            const file = new File([blob], 'generated_image.png', { type: 'image/png' });
            const imageUrl = URL.createObjectURL(blob);
            
            Outputs.status = formatCurrentDate() + ": Image generation complete";
            return { imageUrl, blob, file };
        } else {
            throw new Error('No image generated in the response');
        }
    } catch (error) {
        console.error('Error:', error);
        Outputs.status = formatCurrentDate() + ": Error generating image: " + error.message;
        throw error;
    }
}

// FUNCTION TO MAKE STABLE DIFFUSION API CALL
async function makeStableDiffusionApiCall(apiKey, prompt, imageToImage, image, strength, aspectRatio, negativePrompt, SD_EditMode = "Standard", SD_Model = 'SD3.5 Medium') {
    const formData = new FormData();
    console.log(`SD request being created. imageToImage = ${imageToImage}, Strength: ${strength}, model: ${SD_Model}`);

    // Append required fields
    formData.append('prompt', prompt);
    formData.append('output_format', 'jpeg');
    formData.append('model',SD_Model)
    formData.append(
        'negative_prompt',
        `"blurry", "pixelated", "bad anatomy", "poor lighting", "dullness", "ugly", "boring", "bad hands", "extra limbs", "disfigured body", ${negativePrompt}`
    );

    let url; // Declare URL variable

    // Handle Edit-InPaint mode
    if (SD_EditMode === "Edit-InPaint") {
        url = 'https://api.stability.ai/v2beta/stable-image/edit/inpaint';
        console.log("SD_EditMode = ", SD_EditMode, ", url: ", url)
        if (image) {
            formData.append('image', image);
        }
    } else { // Handle Standard or Image-to-Image mode
        url = 'https://api.stability.ai/v2beta/stable-image/generate/sd3';
        console.log("SD_EditMode = ", SD_EditMode, ", url: ", url)
        if (imageToImage && image) {
            console.log("Processing Image-to-Image with image:", image);
            Outputs.status = `${formatCurrentDate()}: Image-to-Image Started`;
            formData.append('image', image);
            formData.append('mode', 'image-to-image');
            formData.append('strength', strength);
        } else {
            formData.append('aspect_ratio', aspectRatio);
        }
    }

    // Log FormData contents for debugging
    console.log("Form Data:");
    for (const [key, value] of formData.entries()) {
        console.log(`${key}: ${value}`);
    }

    Outputs.status = `${formatCurrentDate()}: Request Sent - Waiting for Image Generation`;

    // Make the API call
    return fetch(url, {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${apiKey}`,
            'Accept': 'image/*'
        },
        body: formData
    })
        .then(response => {
            if (!response.ok) {
                Outputs.status = `${formatCurrentDate()}: Error generating Image`;
                return response.json().then(errorData => {
                    console.error('Error ID:', errorData.id);
                    console.error('Error Name:', errorData.name);
                    console.error('Error Details:', errorData.errors);
                    throw new Error(`Image generation failed: ${errorData.message}`);
                });
            }
            return response.blob(); // Return the generated image as a Blob
        })
        .catch(error => {
            console.error("Error during API call:", error);
            Outputs.status = `${formatCurrentDate()}: API Call Failed`;
            throw error;
        });
}

 // FUNCTION TO GENERATE IMAGE WITH FLUX (Polling version)
async function generateImageWithFlux(apiKey, prompt, fluxModel = Inputs.fluxModel) {
    const generateUrl = 'https://api.fluxapi.ai/api/v1/flux/kontext/generate';

    const body = JSON.stringify({
        prompt: prompt,
        enableTranslation: true,
        aspectRatio: Inputs.aspectRatio,
        outputFormat: 'jpeg',
        promptUpsampling: false,
        model: fluxModel
    });

    Outputs.status = `${formatCurrentDate()}: Request sent to Flux API – waiting for image generation`;

    try {
        /* 1.  Create the task --------------------------------------------------- */
        const postResp = await fetch(generateUrl, {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${apiKey}`,
                'Content-Type': 'application/json'
            },
            body
        });

        if (!postResp.ok) {
            const e = await postResp.json().catch(() => ({}));
            throw new Error(`Flux job start failed: ${postResp.status} ${e.msg || e.detail || postResp.statusText} TaskRecord: ${e}`);
        }

        const initialData = await postResp.json();
        
        // Extract taskId from the initial response (assuming it's under 'data')
        const taskId = initialData?.data?.taskId || initialData?.taskId || initialData?.result?.taskId;
        if (!taskId) {
             console.log("Initial Flux Response:", initialData);
             throw new Error('Flux job started, but the response did not contain a taskId. Check console for "Initial Flux Response".');
        }
        
        console.log('Flux taskId:', taskId);
        
        // *** FIX: Use the confirmed Polling URL (record-info) ***
        const pollingUrl = `https://api.fluxapi.ai/api/v1/flux/kontext/record-info?taskId=${taskId}`;
        console.log('Flux Polling URL:', pollingUrl);

        /* 2.  Poll until finished ----------------------------------------------- */
        const poll = () =>
            fetch(pollingUrl, {
                headers: { 'Authorization': `Bearer ${apiKey}` }
            }).then(r => {
                if (!r.ok) throw new Error('Poll request failed ' + r.status);
                return r.json();
            });

        let pollData;
        const maxAttempts = 150; // 5 minutes max timeout (150 attempts * 2s)
        
        for (let attempts = 0; attempts < maxAttempts; attempts++) {
            await new Promise(r => setTimeout(r, 2000)); // 2-second pause
            
            pollData = await poll();
            const successFlag = pollData.data?.successFlag;
            
            console.log(`Poll Status Flag: ${successFlag}`);

            // Success status: 1 = SUCCESS
            if (successFlag === 1) break; 
            console.log(pollData)
            // Failure statuses: 2 = CREATE_TASK_FAILED, 3 = GENERATE_FAILED
            if (successFlag === 2 || successFlag === 3) {
                 throw new Error(`Flux generation failed (Error Code ${successFlag}): ${pollData.data?.errorMessage || 'Check task record for details.'}, Poll data: ${pollData}`);
            }
            
            Outputs.status = `${formatCurrentDate()}: Still waiting for image generation... Status: GENERATING`;
        }
        
        if (pollData?.data?.successFlag !== 1) {
             throw new Error('Image generation timed out after 5 minutes.');
        }

        /* 3.  Download the picture ---------------------------------------------- */
        // Extract the result from the confirmed structure: data.response.resultImageUrl
        const imageUrl = pollData.data?.response?.resultImageUrl; 
        
        if (!imageUrl) throw new Error('No resultImageUrl in completed task response.');

        const imgResp = await fetch(imageUrl);
        if (!imgResp.ok) throw new Error('Could not download finished image');
        
        const blob = await imgResp.blob();
        const file = new File([blob], 'Flux.jpeg', { type: 'image/jpeg' });

        Outputs.status = `${formatCurrentDate()}: Image generation complete`;
        return { imageUrl, blob, file };

    } catch (error) {
        Outputs.status = `${formatCurrentDate()}: Error generating Image: ${error.message}`;
        console.error('Error:', error);
        throw error;
    }
}

// FORMAT CURRENT Date
function formatCurrentDate() {
  const currentDate = new Date();
  
  // Array of month abbreviations
  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
  
  // Get date components
  const month = months[currentDate.getMonth()];
  const day = String(currentDate.getDate()).padStart(2, '0');
  const year = currentDate.getFullYear();
  
  // Get time components
  let hours = currentDate.getHours();
  const minutes = String(currentDate.getMinutes()).padStart(2, '0');
  
  // Convert to 12-hour format
  const ampm = hours >= 12 ? 'PM' : 'AM';
  hours = hours % 12;
  hours = hours ? hours : 12; // the hour '0' should be '12'
  hours = String(hours).padStart(2, '0');
  
  // Get timezone abbreviation
  const timeZone = Intl.DateTimeFormat().resolvedOptions().timeZone;
  const timeZoneAbbr = new Intl.DateTimeFormat('en', { timeZoneName: 'short' })
    .formatToParts(currentDate)
    .find(part => part.type === 'timeZoneName').value;

  // Construct the formatted string
  return `${month}${day}${year}. ${hours}:${minutes} ${timeZoneAbbr}`;
}

async function callGeminiAPI(promptText, geminiKey, useJsonOutput = true) {
  try {
    const generationConfig = {
  //    temperature: 0.7,
      topK: 40,
      topP: 0.95,
      maxOutputTokens: 2048
    };

    if (useJsonOutput) {
      generationConfig.response_mime_type = "application/json";
    }

    const response = await fetch("https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=" + geminiKey, {
      method: "POST",
      headers: {
        'Content-Type': "application/json"
      },
      body: JSON.stringify({
        contents: [{
          parts: [{
            text: promptText
          }]
        }],
        generationConfig: generationConfig
      })
    });

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const data = await response.json();
    return data.candidates[0].content.parts[0].text;
  } catch (error) {
    console.error("Error calling Gemini API:", error);
    throw error;
  }
}


async function callOpenAIChatGPT(promptText, openAIKey, useJsonOutput = true) {
  try {
    const generationConfig = {
 //     model: "gpt-4-1106-preview",
 //      model: "gpt-4o"
      model: "gpt-4o-mini",
      temperature: 0.7,
      max_tokens: 2048,
      top_p: 0.95,
      frequency_penalty: 0,
      presence_penalty: 0
    };

    const headers = {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${openAIKey}`
    };

    const messages = [
      {
        role: "system",
        content: useJsonOutput ? "You must respond in JSON format. Your response should be a valid JSON object." : "You are a helpful assistant."
      },
      { role: "user", content: promptText }
    ];

    const requestBody = {
      messages: messages,
      ...generationConfig
    };

    if (useJsonOutput) {
      requestBody.response_format = { type: "json_object" };
    }

    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: headers,
      body: JSON.stringify(requestBody)
    });

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const data = await response.json();
    return data.choices[0].message.content;
  } catch (error) {
    console.error("Error calling OpenAI API:", error);
    throw error;
  }
}

async function callPerplexityAPI(promptText, perplexityKey) {
  try {
    const response = await fetch("https://api.perplexity.ai/chat/completions", {

        'accept': "application/json"

  }
}
function extractJson(textResponse) {
    // Remove any non-printable characters
    textResponse = textResponse.replace(/[\x00-\x1F\x7F-\x9F]/g, "");

    // Replace curly quotes with straight quotes
    textResponse = textResponse.replace(/[\u201C\u201D]/g, '"');

    // Remove any leading or trailing whitespace
    textResponse = textResponse.trim();

    try {
        // Attempt to parse the entire string
        const jsonObj = JSON.parse(textResponse);
        
        // If successful, return the string
        return textResponse;
    } catch (error) {
        console.error("Error parsing JSON:", error);

        // If parsing fails, try to fix common issues
        let fixedText = textResponse
            .replace(/\n/g, "\\n")  // Replace newlines with escaped newlines
            .replace(/\r/g, "\\r")  // Replace carriage returns with escaped carriage returns
            .replace(/\t/g, "\\t")  // Replace tabs with escaped tabs
            .replace(/\\/g, "\\\\") // Escape backslashes
            .replace(/\u2028/g, "\\u2028") // Replace line separator
            .replace(/\u2029/g, "\\u2029"); // Replace paragraph separator

        try {
            // Try parsing again after fixes
            const jsonObj = JSON.parse(fixedText);
            return fixedText; // If successful, return the fixed string
        } catch (error) {
            console.error("Error parsing JSON after fixes:", error);
            return null;
        }
    }
}
